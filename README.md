# 🚀 Desenvolvimento Back-End com Node.js T5

Bem-vindo ao repositório da turma de **Desenvolvimento Back-End com Node.js T5**.

Durante esta formação, construiremos uma base sólida em programação utilizando **JavaScript** e **Node.js**, evoluindo dos conceitos fundamentais da linguagem até o desenvolvimento de aplicações back-end.

Este repositório reúne os exemplos, exercícios, materiais de apoio e desafios desenvolvidos durante as aulas.

---

# 📚 Objetivos da Formação

Ao final dessas 4 semanas você será capaz de:

- Compreender como funciona o JavaScript no ambiente Node.js;
- Escrever algoritmos utilizando lógica de programação;
- Utilizar variáveis, operadores e estruturas de controle;
- Trabalhar com funções e manipulação de arrays;
- Criar e manipular objetos JavaScript;
- Utilizar JSON para representar dados;
- Utilizar Git e GitHub para versionamento.

---

# 💡 Boas práticas

Durante o curso procure sempre:

✔ Utilizar nomes de variáveis significativos.

✔ Escrever um código organizado.

✔ Comentar apenas quando necessário.

✔ Manter a identação correta.

✔ Testar seu código frequentemente.

✔ Fazer pequenos commits no Git.

✔ Praticar diariamente.

# 🎯 Como estudar

A melhor forma de aprender programação é praticando.

Sempre que possível:

- Refaça os exemplos das aulas;
- Resolva todos os exercícios;
- Tente criar versões diferentes dos desafios;
- Pesquise a documentação oficial;
- Compartilhe dúvidas com a turma.

> Programar é uma habilidade construída pela prática constante.
